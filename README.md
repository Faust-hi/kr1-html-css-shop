# Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».
https://faust-hi.github.io/kr1-html-css-shop/
## Описание
Учебная версия сайта интернет-магазина, разработанная на Bootstrap.

## Используемый фреймворк
Bootstrap 5.3.8.

## Способ подключения
Локально из vendor/bootstrap/ (CSS — в head, JS Bundle — перед </body>).

## Реализованные компоненты
- navbar (с dropdown и мобильным toggler);
- card (карточки товаров);
- btn (все варианты);
- badge (метки товаров);
- alert (сообщения);
- modal (быстрая заявка в каталоге и на главной);
- form-control, form-select, input-group, form-check (форма заявки);
- accordion (частые вопросы на странице товара);
- carousel (акции на главной и похожие товары на странице товара) — самостоятельная доработка;
- toast (уведомление после отправки формы) — самостоятельная доработка;
- breadcrumb, table.
