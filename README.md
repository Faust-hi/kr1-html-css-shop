Контрольная работа №4

Тема: «Разработка интерактивного интернет-магазина на JavaScript».

Описание

Учебная версия сайта интернет-магазина, доработанная с использованием JavaScript. Добавлены интерактивный каталог товаров, поиск, фильтрация, сортировка, корзина, избранное и валидация форм.

Используемый фреймворк

Чистый JavaScript.

Способ подключения

JavaScript подключается через внешние файлы из папки "js/" с использованием атрибута "defer". Основные скрипты: "data.js", "storage.js", "main.js", "catalog.js", "cart.js", "product.js", "modal.js", "validation.js".

Реализованные компоненты

- Каталог товаров с динамическим созданием карточек.
- Поиск, фильтрация и сортировка товаров.
- Пагинация каталога.
- Корзина с добавлением, удалением и изменением количества товаров.
- Расчёт стоимости товаров и применение промокода.
- Избранное с сохранением в "localStorage".
- Сохранение корзины в "localStorage".
- Модальное окно быстрого просмотра товара.
- Страница отдельного товара.
- Валидация форм оформления заказа и обратной связи.
- Адаптивная навигация.
