# ShopProject — контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Учебный интернет-магазин ShopProject на Bootstrap: каталог техники, страница товара, форма заявки.

## Фреймворк и подключение

Bootstrap 5.3.8 через CDN: CSS — в `<head>`, JS Bundle — перед `</body>`, собственные стили — `css/custom.css`.
